# Known Issues

This project is a beta. The following limitations are known in v21.

## Streets — Valentin sequence

Streets can freeze around the **Valentin** sequence. The issue is intermittent/scene-specific and remains unresolved in this beta.

If testing the mod, save progress before Streets and avoid treating completion of that mission as a stability guarantee.

## Dialogue coverage

The campaign is not a complete dialogue replacement. Some characters have custom GTA-themed speech in selected scenes while other lines remain from the original GoldenEye campaign.

This is expected for the current beta and is not considered a regression.

## Aztec and Egyptian

**Aztec and Egyptian have not yet been validated in the current beta.** Behaviour in those missions should be treated as unknown until they receive a complete playthrough.

## Source snapshot

The public v21 source directory is incremental and depends on earlier development modules that are not part of this snapshot. See `docs/BUILD_NOTES.md`.
