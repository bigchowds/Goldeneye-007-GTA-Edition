# v21 Incremental Source

This directory contains the incremental Python changes used for the v21 beta scene fixes and validation workflow.

It is **not a complete standalone build environment**. The scripts depend on earlier project modules listed in `../../docs/BUILD_NOTES.md` and on the exact previous v20 development build used at the time.

Included here because they document the actual implementation and regression-test approach used for the final v21 changes.
